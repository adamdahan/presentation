# A self-maintaining documentation system

Cross-repository documentation that knows when it has gone out of date, and
corrects itself.

Each document explains how one feature works end to end across several
repositories, and records the exact source files it was written from. When those
files change, the document says so before it answers — and an overnight job
rewrites the parts that are no longer true and asks one person to confirm.
